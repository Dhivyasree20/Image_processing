# Cow Health CV - Image Processing Internship Project

2-week internship project: cow/posture detection and visual health-screening pipeline using YOLO.

## Pipeline
Dataset -> Model (YOLO) -> Health Indicators -> Demo

## Structure
- data/raw - original images
- data/interim - cleaned/cropped images
- data/processed - train/val/test splits
- src/ - pipeline scripts
- configs/ - dataset and training configs
- reports/ - evaluation outputs
